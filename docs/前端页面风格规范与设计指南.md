# JJG Admin 前端页面风格规范与设计指南

> **定位**：本项目前端界面视觉与布局的**唯一权威规范**（2026-11-19 定稿，取代早期分散的 [UI设计调研与改版指南.md](UI设计调研与改版指南.md) 与 [UI改版-逐页问题分析与改进方案.md](UI改版-逐页问题分析与改进方案.md)）。
> **分工**：本文定义视觉原则、设计 Token、桌面端 5 类标准页型、移动端与公开扫码页壳、核心组件视觉规格、暗色模式与禁止红线；交互反馈（Toast、文案、错误翻译、URL 状态、数据格式）同步遵循 [前端交互与反馈规范.md](前端交互与反馈规范.md)。两者存在任何冲突时，视觉与布局部分以本文为准。
> **改造进度**：全站 83 个路由页面的分阶段推进状态见根目录 [todolist.md](../todolist.md)。

## 1. 设计哲学与核心原则

**一句话定位：工业级克制（Calm Industrial）**——视觉权重让位于生产数据与高效操作，拒绝“白卡套白卡”与多余装饰。

| 原则 | 具体标准 | 反例（禁止） |
|---|---|---|
| **1. 单层去套娃** | `AppLayout` 的 `Content`（`app-card`）是桌面端页面**唯一外层白卡**；页面内部不再嵌套带阴影的“搜索白卡 / 表格白卡”，改用轻量浅底或 1px 分割线区分区块 | 在 `app-card` 内再写 `rounded-xl border bg-white shadow-sm` 或再包 `<Card>` |
| **2. 高屏效紧凑** | 面向车间多列高频扫表，全站表格统一采用**微呼吸紧凑密度**，保证一屏可见 10–15 行有效数据且文字清晰不挤 | 同一系统里 97 个表格紧凑、4 个表格突然变高一倍 |
| **3. 主次分明** | 每页工具栏**仅 1 个品牌主色主操作（`type="primary"`）**，其余次操作用中性按钮或克制语义图标；品牌主色总面积 ≤ 10% | 工具栏一排红黄绿蓝彩虹小图标，或满屏多个蓝色主按钮 |
| **4. 亮暗同权** | 所有页面（含员工手机端、公开扫码页、汇总行、斑马纹）一等公民适配暗色模式，所有灰阶严格成对使用 `slate-*` | 漏写 `dark:` 导致暗色下出现刺眼白块或黑字看不清 |

## 2. 设计 Token 体系（唯一色值与尺度来源）

`src/App.tsx` 的 `BASE_TOKENS` 是全站颜色与圆角的**唯一定义处**，通过 `ConfigProvider` 的 `cssVar: { prefix: 'jjg' }` 与 `src/index.css` 的 `@theme inline` 桥接到 Tailwind 工具类。**业务组件禁止硬编码十六进制色值与非语义彩色类。**

### 2.1 品牌色与语义色

| 语义角色 | 浅色基准值 | Tailwind Token 类 | 典型用途 |
|---|---|---|---|
| 品牌主色 | `#2563eb` | `bg-primary` / `text-primary` / `border-primary` | 页面唯一主操作按钮、链接、选中态、聚焦态 |
| 成功 / 完成 | `#16a34a` | `bg-success` / `text-success` | 已完成 / 已审核状态徽章、库存充足 |
| 警告 / 待处理 | `#d97706` | `bg-warning` / `text-warning` | 待审核 / 暂停 / 低库存预警 |
| 危险 / 异常 | `#dc2626` | `bg-error` / `text-error` | 删除确认、超期、异常告警 |
| 信息 | `#2563eb` | `bg-info` / `text-info` | 进行中状态、提示信息 |

- 业务页面中**禁止**再写 `bg-blue-500`、`text-emerald-600`、`text-amber-500`、`text-red-500` 等硬编码色阶来表达通用语义；统一使用语义 Token（`text-primary`、`text-success`、`text-warning`、`text-error`）或 `StatusPill` 组件。
- 业务图表/排产色块等确需多分类调色板的场景，须集中定义在模块内 `palette.ts` 并提供亮/暗两套配对值。

### 2.2 中性色阶（全站统一冷灰 `slate`）

**禁用** `gray-*`、`neutral-*`、`zinc-*`、`stone-*`。

| 层次 | 浅色模式 | 暗色模式 | Tailwind 写法 |
|---|---|---|---|
| 底层画布（Layout） | `#f1f5f9`（slate-100） | `#0f172a`（slate-900） | `bg-slate-100 dark:bg-slate-900` |
| 主内容卡片（`app-card`） | `#ffffff` | `#1e293b`（slate-800） | `app-card`（自动响应） |
| 次级底块（筛选栏/表头/明细浅底） | `#f8fafc`（slate-50） | `slate-900/50` | `bg-slate-50/80 dark:bg-slate-900/50` |
| 边框与分割线 | `#e2e8f0`（slate-200） | `#334155`（slate-700） | `border-slate-200 dark:border-slate-700` 或 `border-divider` |
| 主文字 | `#0f172a`（slate-900） | `#f1f5f9`（slate-100） | `text-slate-900 dark:text-slate-100` |
| 次要文字 / 标签 | `#64748b`（slate-500） | `#94a3b8`（slate-400） | `text-text-secondary` 或 `text-slate-500 dark:text-slate-400` |
| 弱辅助文字 / 占位符 | `#94a3b8`（slate-400） | `#64748b`（slate-500） | `text-text-tertiary` |

### 2.3 字体、字号与数字排印

- **字体族**：全站统一使用系统无衬线字体栈（`App.tsx` `BASE_TOKENS.fontFamily`）。**禁止**在任何页面（包括公开二维码页）使用宋体/衬线体（如 `STSong`/`SimSun`）。
- **字号阶梯**：
  - 顶栏页面标题：`16px` `font-semibold`（由 `AppHeader` 统一渲染，页面内不重复放 `Typography.Title`）
  - 区块小标题 / 弹层标题：`14px` `font-semibold`
  - 正文 / 表单标签 / 控件：`14px`（`text-sm`）
  - 表格单元格（标准紧凑）：`13px`（表头 `12px` `font-medium`）
  - 状态徽章 / 辅助说明：`12px`（`text-xs`）
  - 统计 KPI 大数字：`24px`（`text-2xl font-bold tabular-nums`）
- **数字列强制规则**：数量、金额、单价、工时、重量、百分比统一**右对齐（`align: 'right'`）+ `tabular-nums`**（`index.css` 已对表格全局开启 `tabular-nums`，非表格统计数字需显式加 `tabular-nums`）。

### 2.4 圆角、阴影与间距

| 层级 | 标准值 | 说明 |
|---|---|---|
| 控件（按钮 / 输入框 / 选择器） | `borderRadius: 8px`（`rounded-lg`），小号 `6px`（`rounded-md`） | 跟随 Antd Token，无需手写 `rounded-*` 覆盖 |
| 页面级容器 / 弹层 / 区块底板 | `borderRadiusLG: 12px`（`rounded-xl`） | 桌面与移动端卡片统一上限为 `rounded-xl` / `rounded-2xl` |
| 状态徽章 | `rounded-full` | 仅限 `StatusPill`、小圆点 |
| 阴影 | 仅 2 档：无阴影（页面内元素） / `var(--shadow-card)`（外层 `app-card`、移动端顶层卡） | **严禁**新增任意 `rounded-[...]`、`shadow-[...]`（如 `rounded-4xl`、`shadow-[0_24px_70px_...]`） |
| 间距阶梯 | 4px 基数：`gap-2`（8px 按钮/控件间）、`gap-3`（12px 页面区块间）、`p-3`（12px `AppLayout` 唯一外边距） | 页面根节点**不加**额外 `p-4` / `p-6` |

### 2.5 图标规范

- **唯一图标库**：`@heroicons/react`。
- **桌面工具栏 / 按钮 / 表格行内 / 表单前缀**：统一使用 `@heroicons/react/16/solid`，尺寸固定 `className="size-4"`。
- **移动端底部导航 / 扫码磁贴 / 空状态**：允许使用 `@heroicons/react/24/outline`，尺寸按场景选用 `size-5` / `size-6` / `size-10`。
- **禁止**：禁止新增或保留 `@ant-design/icons` 导入，**禁止手写业务 `<svg>`**。

## 3. 桌面端 5 类标准页型与布局骨架

### A 类：标准 CRUD 列表页（极简扁平单层，覆盖全站 70%+ 页面）

结构顺序自上而下固定（根节点 `flex h-full flex-col gap-3 overflow-hidden`）：

1. **工具栏（Toolbar）**：左侧唯一 `primary` 主操作 → 编辑 / 复制新增 → 业务状态动作 → 导入 / 导出 / 打印 → 删除（末尾）。
2. **筛选栏（`FilterBar`）**：扁平轻底块（`rounded-lg border border-slate-200/70 bg-slate-50/80 px-3 py-2.5 dark:border-slate-700/70 dark:bg-slate-900/50`），**无阴影、无蓝点“筛选条件”标题**；内部单行自动换行，固定末尾「搜索」「重置」。
3. **选中摘要条（`SelectedSummaryBar`，可选）**：仅在勾选 ≥ 1 条且需汇总数量/金额时展示；扁平克制样式（`rounded-xl border border-primary/20 bg-primary/5 px-4 py-2`，无重辉光阴影）。
4. **数据表 + 底部分页**：表格直接铺在主内容区，**不再外包圆角阴影白卡**；高度由 `useTableHeight` 控制，分页固定右对齐在底部。

```tsx
<div className="flex h-full flex-col gap-3 overflow-hidden">
  {/* 1. 工具栏：1 个主操作 + 次操作 */}
  <div className="flex flex-wrap items-center gap-2">
    <AddButton handleCreate={handleCreate} permissionKey="feature:xxx.create" />
    <EditButton title="编辑工装" handleEdit={handleEdit} permissionKey="feature:xxx.edit" />
    <ExportButton handleExport={handleExport} permissionKey="feature:xxx.export" />
    <ImportButton onClick={openImport} permissionKey="feature:xxx.import" />
    <DeleteButton
      onConfirm={handleDelete}
      isDeleting={deleteMutation.isPending}
      count={selectedRowKeys.length}
      title="删除工装"
      itemName="工装"
      permissionKey="feature:xxx.delete"
    />
  </div>

  {/* 2. 筛选栏：统一 FilterBar 壳，无外卡套娃 */}
  <FilterBar>
    <XxxSearch onSearch={handleSearch} onReset={handleReset} values={filters} />
  </FilterBar>

  {/* 3. 选中摘要条（按需） */}
  {selectedCount > 0 && <SelectedSummaryBar ... />}

  {/* 4. 表格 + 分页（直接渲染，不再外包白卡） */}
  <div ref={tableContainerRef} className="flex min-h-0 flex-1 flex-col gap-2 overflow-hidden">
    <div className="min-h-0 flex-1 overflow-hidden">
      <TableState loading={isLoading && !data} error={error} onRetry={refetch}>
        <XxxTable ... />
      </TableState>
    </div>
    <div ref={paginationRef} className="flex shrink-0 justify-end">
      <AppPagination total={data?.total ?? 0} />
    </div>
  </div>
</div>
```

### B 类：主从分栏 / 上下联动页（`material-transfer`、`machine-runtime`、`precision-*`）

- 根节点同样为 `flex h-full flex-col gap-3 overflow-hidden`（**禁止加 `p-4`**）。
- 使用 Antd `<Splitter orientation="vertical">`，上下两个面板内使用**轻量区块头**（`text-xs font-semibold text-slate-500 dark:text-slate-400` + `border-b border-divider pb-1.5`），**禁止**在每个面板里再套 `<Card size="small">`。

### C 类：详情页与配置表单页（`PoDetail`、`ReportDetail`、`SafePartSetting`、`SyneySetting`、`JobBaseSetting`）

- 根节点不加额外大内边距，使用 `flex h-full flex-col overflow-hidden`。
- 顶部：轻量操作/返回条（`border-b border-divider pb-2.5`，左「返回列表」+ 摘要标识，右主要动作）。
- 中部：可滚动区域（`min-h-0 flex-1 overflow-y-auto py-3`），字段分组用 `border-b border-divider` 或淡底分组块（`rounded-lg bg-slate-50/70 p-3 dark:bg-slate-900/40`）组织，不使用多张重阴影 `<Card>`。
- 底部（长表单编辑场景）：`border-t border-divider pt-3` 吸底提交栏。

### D 类：报表 / 统计 / 看板页（`OrderStatusDashboard`、`AttendanceStats`、`ProductionDailyReport`、`*MonthlyReport`、`Dashboard`）

- 顶部汇总指标（若有）：扁平 KPI 条，Grid 自适应（`grid-cols-2 sm:grid-cols-4 gap-3`），每格 `rounded-lg border border-slate-200/80 bg-slate-50/60 px-3.5 py-2.5 dark:border-slate-700/80 dark:bg-slate-900/40`（标签 12px 灰字 + 大数字 24px 粗体 `tabular-nums`）。
- 报表汇总行：统一底色 `bg-slate-50 font-semibold dark:bg-slate-800/80`，严禁写死 `!bg-slate-50`。

### E 类：标签页容器页（`AccessManagement`、`VillaLiftOrderList`）

- 根节点**不加 `p-4`**，直接使用 `flex h-full flex-col overflow-hidden`。
- `<Tabs size="small" className="mb-0!" />` 置于顶部，各 Tab 内容区遵循 A 类或 C 类骨架，避免顶部双层留白。

## 4. 移动端与公开扫码页统一规范

### 4.1 员工手机端壳（`EmployeeMobileLayout`）

| 区域 | 统一规格 |

### 4.2 免登录公开二维码页（4 页共用 `PublicQrPageShell`）

统一收口劳保领用、刀具出库、金檀配件出库、工装使用登记 4 个公开页：

- **统一视觉**：去掉不同渐变背景、去掉宋体标题（`STSong`）、去掉模糊光斑、去掉深黑头图；改用 `PublicQrPageShell`：
  - 画布：`bg-slate-100 dark:bg-slate-950`
  - 顶部页头卡：`rounded-2xl border border-slate-200 bg-white p-5 dark:border-slate-800 dark:bg-slate-900`，顶部 3px 品牌主色细条（或淡主色徽标「免登录扫码登记」）+ 无衬线粗体标题 + 一句操作指引
  - 表单/详情卡：`rounded-2xl border border-slate-200 bg-white p-5 dark:border-slate-800 dark:bg-slate-900`
  - 表单控件：`size="large"`（高度 ≥ 40px）、数字输入加 `inputMode="decimal"` / `"numeric"`、提交按钮吸底或全宽 `h-11` 主色按钮
  - 结果态：统一使用 Antd `<Result>`，保留提交快照摘要与「继续登记」主按钮

## 5. 核心组件与交互标准

### 5.1 按钮层级与工具栏排序

| 层级 | Antd 形态 | 图标颜色 | 适用按钮 |
|---|---|---|---|
| **主操作（每页最多 1 个）** | `type="primary"` | 随按钮反白 | `AddButton`（默认 `variant="primary"`；非主入口场景可显式传 `variant="text"`） |
| **常规业务操作** | `type="text"`（统一中性风格，页面内不混用多种形态） | `text-slate-600 dark:text-slate-300`（语义强调仅限 `text-primary` / `text-success` / `text-warning`） | 编辑、复制新增、批量审核/反审核、导出、导入、打印 |
| **危险操作** | `type="text" danger` | `text-error` | `DeleteButton`（带 `Popconfirm` 二次确认，确认按钮 `danger` + 文案「确认删除」） |
| **空态引导按钮** | `AddButton`（主色按钮） | 反白 | `TableEmpty` 的 `action` |

**工具栏从左到右固定顺序**：
`新增（primary）` → `编辑` → `复制新增` → `业务状态动作（审核/反审核/结案）` → `导入 / 导出 / 打印` → `删除（末尾）`。

所有带权限控制的按钮无权限时一律**禁用 + Tooltip 提示原因，不隐藏**。

### 5.2 搜索筛选栏（`FilterBar`）

- 统一使用 `<Form className="flex flex-wrap items-center gap-2" onFinish={...}>`，每个 `<Form.Item className="mb-0!">`。
- **按钮文案统一**：主搜索按钮固定「**搜索**」（`type="primary" htmlType="submit"`，支持回车提交），重置按钮固定「**重置**」（不再出现“查询”或“清空”）。
- **控件宽度 3 档标准**：
  - 短选择 / 状态 / 短编码：`w-36`（144px）
  - 常规关键字 / 单号 / 姓名：`w-52`（208px）
  - 日期区间 / 多字段模糊搜索：`w-64`（256px）
- **状态同步**：筛选条件、页码、每页条数同步到 URL（`replace: true`），刷新和切页签不丢条件。

### 5.3 数据表格（统一微呼吸紧凑密度）

1. **统一紧凑配置**（`src/App.tsx` `TABLE_TOKENS`）：
   - 标准紧凑密度：`cellFontSize: 13`、`cellPaddingBlock: 6`、`cellPaddingInline: 10`。
   - 极密看板/排产矩阵：`size="small"` 局部降级到 `12px / 4px / 6px`。
2. **边框与斑马纹**：
   - 普通数据表**默认不加 `bordered`**（仅复杂多级表头/矩阵排产表允许 `bordered`）。
   - 全站主列表表格统一使用 `src/ui/tableStyles.ts` 导出的暗色兼容斑马纹函数 `zebraRowClassName`。
3. **三态闭环（强制）**：
   - 首屏加载：`<TableState loading={isLoading && !data} error={error} onRetry={refetch}>`（骨架屏）
   - 翻页/筛选加载：`<Table loading={isLoading} ... />`（`keepPreviousData` 下不闪骨架）
   - 空态：`locale={{ emptyText: <TableEmpty title="暂无xxx" action={...} /> }}`
   - 错误态：查询 hook 配 `throwOnError: false`，由 `TableState` 展示中文原因 + 重试 + 可折叠技术详情
4. **状态展示**：全站状态列**只用 `StatusPill`**（`success / info / warning / danger / neutral`），同一业务域的状态映射集中放在 `<domain>/statusTones.ts`，逐步清零表格里的 `<Tag color="...">` 与手写彩色圆角 `<span>`。

### 5.4 弹层与表单

| 场景 | 容器 | 宽度规格 | 核心规范 |
|---|---|---|---|
| 新增 / 编辑表单 | `<Modal destroyOnHidden>` | **严控 3 档**：`520`（≤6 字段，默认）/ `720`（两列表单）/ `960`（含明细子表） | `Form layout="vertical"`；顶部放 `<FormErrorAlert error={formError} />`；提交失败不关弹窗、保留输入；按钮用 `confirmLoading` |
| 宽只读详情 / 关联流水 | `<Drawer>` | `560`（常规）/ `760`（含子表） | 分区信息使用 `<Descriptions size="small" column={2} />` 或淡底网格 |
| Excel 批量导入 | 共享 `<ExcelImportModal>` | `960` | 统一“下载模板 → 选择文件 → 解析错误列表（`ExcelParseErrorList`）→ 预览表 → 确认导入”五步交互 |
| 高风险确认 | `DeleteButton`（Popconfirm）或 `modal.confirm` | 默认 | 确认按钮 `danger: true`，明确对象与影响数量 |

## 6. 暗色模式检查清单与反模式红线

### 暗色模式必检 5 项
1. 任意 `bg-white` / `bg-slate-50` / `bg-slate-100` 必须成对写 `dark:bg-slate-*`。
2. 任意 `text-slate-700/800/900` 必须成对写 `dark:text-slate-100/200`，次要文字暗色不低于 `slate-400`（保证 WCAG AA 对比度）。
3. 任意 `border-slate-200` 必须成对写 `dark:border-slate-700` 或改用 `border-divider`。
4. 表格汇总行、选中行、警告行必须使用 `index.css` 中定义的 CSS 变量或成对 `dark:` 类。
5. 移动端和公开扫码页切暗色后无亮白刺眼卡片与失效边框。

### 禁止清单（由 `src/ui/uiStyleConventions.vitest.ts` 渐进式自动化拦截）
- 禁止在桌面列表页根节点写 `p-4` / `p-6` 或在 `app-card` 内再套 `<Card>` / 阴影白卡 / 蓝点“筛选条件”卡片。
- 禁止新增 `@ant-design/icons` 导入或业务手写 `<svg>`。
- 禁止新增 `gray-*` / `neutral-*` / `zinc-*` / `stone-*` 灰阶类。
- 禁止新增任意 `rounded-[...]` / `shadow-[...]` 和衬线字体（`STSong` / `SimSun`）。
- 禁止新增 3 档（`520 / 720 / 960`）之外的 `<Modal width={...}>`。
- 禁止使用 `.ant-*` 私有类名做样式穿透。
